# Tamil Nadu Car Simulator

Single-file browser driving game (Three.js r128, plain JS, real OpenStreetMap roads).

## Step 1 (done)
- Main menu: profile, level/XP, coins, diamonds
- Daily rewards, stats, achievements
- Settings: language, graphics, steering sensitivity, player name, reset
- Progress and settings saved in localStorage
