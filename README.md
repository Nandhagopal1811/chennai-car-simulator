# Tamil Nadu Car Simulator

Single-file browser driving game (Three.js r128, plain JS, real OpenStreetMap roads).

## Done
- Step 1: main menu, profile/XP, coins/diamonds, daily rewards, stats, achievements, settings, saved progress
- Step 2: garage and car shop (5 cars, buy/select, colours, drag to rotate, front/side/rear views; car stats change top speed, acceleration and handling)

## Planned
3. Driving HUD, pause menu  4. Cameras, mini-map, GPS  5. Tamil Nadu map picker, day/night, rain, traffic
